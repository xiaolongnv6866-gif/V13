# V13｜同题实际训练协议（默认：退婚）

目标不是让模型学会说“为何没写好”，而是连续创作同一题目的完整作品，并由真实反馈推动越来越好的选择。

## 工作项长什么样

一个同题训练有五个互相独立的东西：

- `PROMPT_LOCK.md`：固定时代、地点、人物身份关系、最初矛盾、必须发生的核心事件、要保留的关键人物；一旦锁定，未经作者同意不得悄悄漂移。**更换艺术处理不是更换题目。**
- `drafts/V001.md`, `V002.md`...：每次完整可读的场景稿，不用思路摘要替代。
- `feedback/V001.md`...：作者原话及对应版本，可有“喜欢的确切段落”“读不下去的位置”“希望下一版改变的事情”。
- `manifest.json`：版本父子关系、稿件哈希、写作假设、模型自评与作者判断清楚分开。
- `comparisons/V001_to_V002.md`：真实稿间差异记录。它是学习凭证，不是给小说读者看的说明书。

**退婚基线**：可从 V13 已有 TX01 机制研究读出“婚事在不同人那里有不同价值”，但新正文需要原创人物/安排，不能把《铁血残明》的具体退婚场面搬来。用户口中的“完全相同”指同一练习输入和已确定场面，而不是复制受版权保护的原著。

## 第一次：让一个完整故事成立

在固定的婚事背景里，交付完整现场：谁先安排会面、要拿走或留下什么、说话时谁不方便开口、谁最终改变了行动、离场后关系如何继续。别先搞一页论证。文本质量以读者愿不愿意读下去为本；可以幽默、市井、温暖、冷酷，不能因技术训练而把所有人写成辩论选手。

## 后续每次：保持题，真正换写法

1. 读最新完整稿与用户针对该稿的反馈，确定上一稿最严重的**故事缺陷**；允许多问题共存，不只处理最后出现的一条。
2. 写一个**可检验的修订假设**（内部一句够）：换谁先行动、使原来局外人有自己的损失、从不同角度进入、把会议室式解释变成可以改变关系的事件等。
3. 产出**完整下一稿**：场景可全部推倒重构，但时代/关系/事件实质仍同题；不是换名字、删形容词和替换三行对白。
4. 读新旧稿本身，具体列出行动顺序、各方独立选择、信息迟滞、情绪自然性、时空与利益的改变；自评只是下轮待验证观察。
5. 接收**作者针对该稿的判断**。记录“进步 / 退步 / 有好有坏 / 未评”，保留原话。没有作者反馈时，下一稿也不能宣称成功。

不设固定“五轮必成”承诺，不因写了十五版便认为质量自动改善。能持续变强的必要证据是**同题读者认可，随后陌生题目也能写好**。

## 同题比较：审的是人和戏，不是合规计分

有价值的比较应能指出：

- 某个本来只是替主角讲道理的人，在新版里有了不依赖主角的行动；
- 某个解释性结论被事件证据替代，读者自己推断；
- 某段貌似聪明的完美退让，被符合利益的坚决不合作取代；
- 某个配角说话已经有了只有此人会说的口气；
- 某个更复杂的安排反而削弱了直接的阅读趣味，应恢复旧版的有效部分。

报告“新版达到了15项标准”不能替代以上作品证据。

## 真正有效的失败回写

记录：上一稿为什么被否决、对应证据片段、下一稿实际如何改写、作者是否认为改变有价值。成功案例与失败案例同样留下可检索路径。没有经过用户认可的结论标`MODEL_HYPOTHESIS`，不把它固化成通用写作真理。

新的题目迁移时，检索**成功的选择机制**，不是套用退婚的道具、人物、场景结构。源案例及已练习题要与新测试题分开，避免“提前看题”的伪盲测。

## 工具协作

在实际可运行脚本的环境，可用 `python3 skills/v13-writer-mind/scripts/scene_lab.py` 完成版本保留与反馈入库：

```bash
python3 skills/v13-writer-mind/scripts/scene_lab.py init --root training/scene_lab --case tuihun --prompt /path/to/approved-scene-lock.md
python3 skills/v13-writer-mind/scripts/scene_lab.py submit --root training/scene_lab --case tuihun --draft /path/to/new-original-scene.md --hypothesis "让未婚妻先决定如何处置婚书"
python3 skills/v13-writer-mind/scripts/scene_lab.py feedback --root training/scene_lab --case tuihun --version V001 --file /path/to/user-feedback.md --verdict worse
python3 skills/v13-writer-mind/scripts/scene_lab.py status --root training/scene_lab --case tuihun
```

脚本不调用LLM、不擅自判定作品优劣、不批准Canon，也不自动生成正文；它只负责训练数据的可靠保留。用户还没有确定同题锁前，不要自行声称锁已经批准。
