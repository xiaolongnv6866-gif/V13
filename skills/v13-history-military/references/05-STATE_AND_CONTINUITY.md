# 事件源式状态账｜先发生，再更新

使用 templates/STATE_TEMPLATE.json 的事件序列而非记忆印象。读最近两章 + 最近状态账。六类信息：时间/地点、物资与现银、已经承诺但未兑现的义务、权限有效范围、人物分层所知、可见事件与未决因果。

- planned ≠ promised ≠ authorized ≠ executed ≠ received。
- 声称已付而没有收款事实，只可记“说法/待核”，不能记已结清。
- 准许发粮4袋不意味着可以发5袋；批准卸货不代表隔河货已到目的地。
- 已有身份不等于上级给了出兵的全权，口头传话也不等于书面正式许可。
- 下一章开始前读 expected_balances、open_loops、characters，写完只按有证据的新 events 改账；脚本会机械拒绝负余额、倒时间、未授权发放、凭空增货等。
- 校验器不是历史真实性测试，也不能解决人心是否可信，读者是否被吸引。

允许历史/架空两栏。任何未经外部证实的明代硬数字、具体官制、征粮法规、价格，只能写为小说设定。
