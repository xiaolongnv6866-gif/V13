# V13 STORYCRAFT｜从“知道小说知识”到“做出好看的小说”

**入口承诺：** 给定一组人物、时代和已发生的事实，你要真的创造新故事——提出人物自己想不到的机会、独特的说法与动作、有趣的人与人误解、读者愿意跟下去的选择，以及能继续长成大故事的后果。**不是再总结“小说应当好看”或按表格勾选爽点。** 策划时交付好看的事件，写作时交付真正的小说。

## 这套SKILL跟旧版根本不同在哪里

旧V13将64张能力卡的「不许把批准等于到账、声望等于实力、官职等于指挥」当作主要生产动作，结果小说合理而无趣。本版重新组织为**“生成想法 → 让人行动 → 产生戏剧现场 → 从赢得的事物长出后文 → 反向约束校验”**的创作循环。历史、财政、组织、社会、文学与Nuwa模型**始终参与同一次判断**，却不抢在人物和故事前面生成任务列表。

此SKILL是新的独立入口 `skills/v13-storycraft/SKILL.md`。旧版 `skills/v13-history-military/` 原样保留为研究证据和对照，不需要与旧版串联逐个运行才能用本版。**本版自带完整创作法和来源边界；只有用户要求考据到64卡原证时才回查旧仓库。**

## 遇到用户任务，直接做哪种工作

- **想故事/重设计主干**：执行下文「创意采矿→三种走法→现场试演→后果长大」，输出**人物实际做了什么**和为什么想看下去；不先均分卷数和章节数。
- **设计长期大纲**：先把最有生命力的若干故事连成有来历、有后果、会回头找人的因果链；再反查终局和历史节点，最后才分卷/章。**章数是结果，不是故事材料的配额。**
- **写正文**：不把内部设计、心理理论和账目表写成旁白；在具体地点以动作、鲜明对白、人物隐而不宣的欲望和有限视角写出完整事件。
- **审稿**：先像读者一样读，不打开自评分表；找哪里开始不想读、谁像工具人、哪句本该好笑却在讲道理、哪些“成功”只由叙述者宣布；实际重写再审历史连续性。
- **续写**：先核对最后两章、Canon、角色所知及未完事，**用旧人物还想得到的东西**推动下一场，不新刷陌生刁难者。

## 核心“创作动作”｜在脑中做，不填进正文

### 第1幕：先听见活人的欲望

从已有世界中选出正在忙自己事情的2—4个人。每人都需有一句**私人的、不体面的或不肯当面说出的真实想法**，且不必与主角相关。例如：想保住明天的铺面租客、怕妻子知道已经借钱、想体面离开一份差事、想让父亲第一次求自己帮忙。不能只写“维护阶级利益”“促进商业发展”。

**先让这些人认真地做原本就要做的事**，再让主角闯入。至少一人可以拒绝主角，并有不必因主角聪明就改变的理由。主动打破「一个官员刁难，主角解释，官员折服」同构。

### 第2幕：从生活里挖到“别人没在争的东西”

对同一件普通事尝试**三种完全不同的看法**：这事对甲是体面，对乙是收入，对丙可能是亲情、偷懒、身份、时间或未来的自由。不要把三套理解写成“利益分析报告”，要在一句不合时宜的话、藏起来的物件、谁先上前、谁迟疑的动作里看见。

让主角**想要具体、真实、稍有私心的结果**，而不仅想改革世界。其现代思维的优势可以是重新确定何者值得争、把两项原来分开的条件放在一起、识破误把名分当实际利益、早一步发觉未来成本；但要符合**明代已有聪明商人、懂契约官吏与真正有权力的皇帝**。不能靠现代术语或古人降智。

调用 `references/01-INVENTION_OPERATORS.md` 的**至少两种不同创意变换**，在同一材料上生出竞争方案。操作不是“每场都强制反转”，也不是套古书情节。

### 第3幕：把三种可能写成能看见的事

幕后产出三个候选，各不超过五句话：**开门第一眼看到什么；谁真实在争什么；主角/关键人物干出什么不按惯例的事；别人的反应；具体赢/亏/喜剧或情感余波**。三方案必须在**人物选择**而非地点与官名上不同。

从三者选一个，再立即试写**一段至少350字的现场（不是解释提纲）**。问自己是否愿意继续跟这个人待十分钟：有没有明确说话的人、可观察的动作、意外但合乎个性的回话、对方不服务于主角的行动？若没有，换故事核，不靠扩大历史冲突和加密谋修复。

**默默看见成功的样子：** 主角原先想得到一件事，经历人物碰撞后，确实得到或选择放弃它以换取更珍视的好处；一个配角由此有了**自己的下一个动作**。不是“众人佩服”“影响力提高”。

### 第4幕：让后果把小事养大（长篇核心）

选中的场景之后写**“谁得到了什么，谁的打算从此不同”**。不是机械勾“不可删除”，而是看：
- 这个人的私欲/误解/亏欠往后还会不会出现？
- 这次得到的**真人、真实信任、职位权限、银钱、交易对手、秘密或受伤的面子**，在下一次关键事里可能怎样被用到？
- 胜利造成一项新条件，谁会据此主动争取别的东西？**下一件故事从这人自己的动作开始，而非作者插新任务。**
- 亲情和无目的幽默可以享有空间；不强迫每顿饭做国家主线伏笔，但也不能拿重复琐事填长篇缺口。

用 `references/02-SERIES_GROWTH.md` 将真实故事核扩展为连续弧：有能力写500章，只因为有50件相互生成的变化；不能先列500件事让它们假装有关系。

### 第5幕：同一时刻让现实约束纠偏，而不是事后补借口

**九域一起起作用**：①真实人的目标、欲望与性格②戏剧节奏与喜剧③历史及地理④身份、职权、君臣关系⑤现金/公款/私产/工匠/军饷⑥组织、战争与社会⑦视角和信息时差⑧长期关系与后续因果⑨正文语言、AI味及读者乐趣。Nuwa的四镜片贯穿：资格≠认可(M1)、公共成绩≠私人情感(M2)、承诺≠兑现(M3)、看到/听说/奏报≠同一真相(M4)。有冲突时重做人物选择，**不是增写一段“解释为什么可以”。**

**特别禁区（从作者驳回稿学到）**：
- 崇祯是有独立政治人格的君主，不是让主角递“现代方案”或让主角说服的现代企业主；1639军职不足以让陈干预全国政令。1644南迁议本来就有人提出，不能写成陈“第一次想到南迁”。
- 唐王奉旨给**五万两实际白银**、皇帝给予可掌约千人的合法军职，是锁定事实；**军务款项不可未经授权转成私人商路或澳洲资产**。私人收入必须有来源、权属、时间与交易人。
- 五名锦衣卫随陈往南阳**只有观察办事和报告权，没有调兵、处分、发号施令、接管财物或替皇帝拍板之权**。
- 1641唐王获救与否、具体史人走向、结婚法律形式、胜清时点均属**待作者决定**，不可把往次被否决剧情偷变Canon。
- 陈启明在主要目标上得胜，局部嘴上吃瘪、情感误会与未料到别人的心思仍可有趣；古人必须聪明，胜利须在时代里真实可行。
- 不复写《晚明》《铁血残明》的角色、可识别桥段、原文笑话或作者个人文风。

### 第6幕：从草稿的失败中重新创作，不再加规则

**先读完整作品**，说出三个真正会让读者停读的地方，改**场景方向/人心/叙事**优先于改句法；若旧稿历史权限不成立，**推倒这个具体故事**，而不是编一千字补丁。修后再核事实、角色知情与后续状态。作者否决即撤回故事，在Canon中保留否决边界，不再把坏大纲当新创作的起点。

## 对任务的实际输出

默认只给用户要的东西：用户要故事给**具体的故事**，要主干给**真正在推动对方行动的连续故事群**，要正文给**正文**。幕后备选、九域审稿及结构记账放到产物/附档，**不要让创作工具显形**。输出状态诚实区分 AUTHOR_APPROVED / USER_REVIEW_PENDING / AUTHOR_REJECTED；没有独立测试不得宣称该SKILL“已经变成模型的永久能力”。

## 文档结构（从这个入口完成一个任务）

- `references/01-INVENTION_OPERATORS.md`：从平常事生成意外人物行动的十个**创意变换动作**，含虚构例子与失败反例。
- `references/02-SERIES_GROWTH.md`：从一件活事长出长篇，含史实、群像、财政、君臣政治、反事实审计与卷章节奏。
- `references/03-SOURCE_TO_ABILITY.md`：两书证据定位、旧64卡的能力迁移与Nuwa四模型，明确什么是原文观察/研究者归纳/新SKILL试验。
- `examples/ORIGINAL_LAB.md`：全新创作种子→三种改写方向→场景试演→连续两次变形，**不引用原著原文**。
- `tests/QUALITY_TRIAL.md`：使用同一输入盲写、败因定位、编辑改写及作者评判标准；测试报告不得伪造。

需要外部史实时，实际查史料或标待核；需要延续既有小说时，必须读取 `novels/chen-qiming/PROJECT_BIBLE.md`、最新正文与STATE，已被作者否决的 `STORY_SPINE_V0_1_PROPOSAL.md` **不得当续写基础**。
