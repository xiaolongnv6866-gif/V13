# V13 原创历史军事长篇写作 SKILL｜可运行实验版（未认证）

> 只适合实验及诊断。它不是仓颉/女娲原版已经完成蒸馏、Stage4、Nuwa Phase4–5或正式融合产品。不得假定任何候选方法通过独立V3；上游两套锁定SKILL的质量门仍然由V13执行计划逐项完成。

## 触发与路由

适用：用户要求原创历史军事长篇的世界构建、全书规划、单章正文、章节续写、场景重写、因果/状态审稿与存档恢复。小说创作稿必须有原创人物及事件，不能仿写《晚明》《铁血残明》人物、事件链或作者独特表达。

不适用：用户仅需要历史事实问答、现实作战步骤、现成小说续篇或作者原文仿写；此时应路由到适当信息研究/版权安全任务，而不是本写作工作流。

## 前置输入

尽力获取：创作时期与地点、主线目标及结局、核心人物、故事冲突、世界约束、时间线、当前章节需求、已有状态文件。只有一个小说意向时，可以提出明确标注为“临时创作假设”的最小原创设定并先产出试写，不能把虚构制度当历史事实。对真实政策、爵衔、价格、军制缺来源者不得写成可核实史实；可用虚构机构与非确切说法保留故事。

若续写，优先读取上一轮的 WORLD / STATE / TIMELINE / UNPAID_PROMISES / CHARACTER_KNOWLEDGE，再读取最新两章正文；禁止只凭记忆续写。没有状态则从现有正文重建，并把不确定事实标UNKNOWN。

## 固定执行协议

1. **目标与范围**：用一句话定义本次的可观察交付：“从哪一状态走到哪一状态、读者为何想看下一章”。历史与虚构事实分两栏。不能仅说“写得真实、文笔好”。
2. **终局倒推**：先确定人物最终不可逆的抉择、政治/社会代价及兑现时点，再倒推卷→故事弧→事件链→章→场景；长篇不能只做一条“升级打怪”线。测试型短篇也要写本地终局和未偿债。
3. **五类账本**：①时间地点与人员 ②现货/现钱/债务/预期 ③机构许可—执行—撤回条件 ④每人所见/所闻/所猜/已证 ⑤关系、伤害、承诺与后续追偿。所有“决定已作”不等于“兑现已成”。
4. **逐场强制设计**：确定有限视角及该人不知道什么；谁带着具体诉求入场、另一人的独立目标、核心阻力、现场动作和对白、第三方对结果的反应、状态差值、下一场必然问题。场景必须在动作中发生；删掉“大家都明白”“局势紧张”等解释性旁白，保留读者自行判断的余地。
5. **正文而非摘要**：给出有空间关系、物件、动作、对白潜台词、阻挡与后果的完整场景。场面可跨视角切换，但每次切换必须使信息差产生新价值。大场景推进要有时间与消息时延；人力与运输不可凭空出现。
6. **军事与制度边界**：写战争必须有有限视角、补给与责任后果；不得把历史小说当作现实操作指南，危险武器/伤害技术细节非必要不得写。实际制度须外部来源，否则将制度设定标为虚构。
7. **持续账更新**：写完一章逐项更新库存、款项、权限、人物态度与亲见；把未知和传闻保持未知，避免角色跨章全知。新承诺单列欠账，附预计兑现章节或明确未定。
8. **审稿和修复**：先列具体失效点（数额透支/跨时空消息/随意授权/镜头乱跳/解释性旁白/戏剧不成立/角色没有独立利益），再直接改写相关场景，复查是否引入新事实错误。自评写 DIAGNOSTIC_ONLY，不等同外部读者或独立评委。
9. **运行完毕交付**：完整正文、可续写 STATE.json、世界约束、章节索引、下一章冲突入口、失败与修订账。正式需要经过原版两SKILL所有适用阶段和独立运行/用户确认才可升级认证。

## 运行用输出合同

### PLAN
- 作品终局 / 主要政治与个人代价 / 主角和非主角自主行动 / 卷-弧-事件-章四层任务
- 逐章场景表：视角 | 当前已知 | 现场目标 | 阻力 | 不可逆变化 | 未偿因果

### CHAPTER
- 完整原创中文正文，不以节选或提纲替代
- 以可见事件进入；句式为文学叙事，不把“注意事项”混入正文
- 附准确的场后事实状态与“下一章必须偿还什么”链接，状态账放正文之外

### STATE
机器可读的：absolute_time / location / actors / inventory / cash / receivable / payable / authorization / knowledge_by_pov / promises / contradictions_open / next_scene_trigger。事实状态不要复写推测为confirmed。

### AUDIT
对每一缺陷写：位置→可观察问题→损失→原稿/修改说明→新回归测试→残留不确定。失败案例及历史版本保留。没有独立评委时不得填独立评分。

## 明确判停

若缺真正关键资源、人员许可或事实证据，不应让故事突然满足条件；改写为人物争取、被拒绝、再选择的现场。若没有原文方法V1/V2/V3三门，不能把此实验卡称“源作者认证能力”。若没有新聊天实际加载、连续小说真测与独立盲评，不能宣布正式产品完成。
