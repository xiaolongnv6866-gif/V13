# 《潮汛账》CH04｜功能续写审稿与证据界限

测试分类：同一执行Agent的原创第四章和自审，仅做 ALPHA 功能回归，**不抵W01独立V3、W02原20个独立C、W11四臂或新聊天加载验收**。前3章冻结输入与原测试保持原样。

## 事前条件（由CH03既有状态约束）
- 干粮14袋、湿粮隔离6袋、承诺未到12袋；公银3两、旧工欠0；船行过河预付8两未付。
- 东岸17户是HEARSAY，河东收粮为0；两张单据均未验证谁经手、谁收货。
- 方启闻有本地临时4袋许可但已执行完毕；陆时安无擅行河东/支银/开粮权限。
- CH04不得凭新纸自动写成已交粮、已偿债、已雇船、已定罪。

## 新增的可见选择与代价
- 沈茂生拒绝交出原单，只在有回执时提供供核字面；他有脚钱和雇主信任的独立目标。
- 吴嫂用空碗压纸，要求当面复述与避免虚假担保；并没有变成陆时安的廉价证人。
- 苏鹭限定见证范围，不借官署面子承担河运责任。
- 方启闻在旁人目睹下签署“仅核字面”，因此承担公开承认未结案的政治风险，但仍掌握陆时安能否过河的批准权。
- 两张纸同号异日、新封套传闻，只生成调查线索，不自动判伪或证明货物曾交接。

## 审稿后保留的缺点
- 对原有三章的“议事+单据”情境仍有相似性，下一章应转入岸边、商路或人际走访，以行动兑现不同舞台，不宜继续困在桌边。
- 历史官署/仓务术语和价格均属虚构设定，没有独立史料证明。
- 同一创作主体自我语义评审不可替代真正不同的文学盲审。
- 未来是否能过河、原封套真伪、祁四娘身份与利害均未证实；不能为了结案补写为已知。
