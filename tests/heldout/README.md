## 有限而诚实的盲测定义

本轮封存由当前助手组织，**所以这不是已经完成“独立考官命题”的真双盲实验**；本助手可能在当前上下文中知晓设计的题型。为达到可信的原创写作能力出厂检验，后续需要：
1. 先冻结候选SKILL与基线、测试模型与参数；训练/改技能的Agent不得访问私有题目或密钥。若本次建题Agent与后续考核Agent上下文重叠必须披露并改用独立评委的新保留题，不能称自己“没见过”。
2. 独立测试保管者核对`COMMITMENT.json`的SHA，确认封包未篡改，再在隔离评测环境中开启题库。只在此时解密，生成作答和批量评分任务。
3. 完全相同的陌生任务/限制对比无SKILL baseline与有SKILL candidate，随机隐藏组名，答题者不能访问评分者标准；评分者与答题者必须是不同真实执行主体，不许同一模型单次自答自评冒充双Agent。
4. 判据应包括情节因果、人物自主、现场信息、对白节奏、历史/财政/时间约束、原创性、证据诚实性、跨章连续性、边界与失败样例。不能单看语言华丽程度。报告绝对分数、相对改进、异常、最弱例、复测及评委独立性。
5. 题目一旦泄露给训练或开发Agent，则将此题库标记 `CONTAMINATED`，不能用于出厂保留评分；须由独立出题者另建新库并冻结新的提交，保留旧SHA以供审计。**不能悄悄换题再声称提高。**
