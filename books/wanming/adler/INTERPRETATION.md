## 二、十项核心叙事命题：解释、正证、限制与反证

下列十项为**研究者重新表述的、可被原文修正的叙事命题**，不是作者自述的“十条理论”。每项均有多个原始 XHTML 段落来源，详情及原 SHA 见表格。一个原文位置能支持可见事实，不意味着能独立证明因果的全部解释。

### P01｜后世知识必须先换成当地人承认的生存、工作与信用

- **情节事实**：开篇陈新需要立刻解决生存、身份和随行者问题；进天津后，刘民有找不到满意的账房职位，陈新学习如何在传统账房、熟人和官面网络中落脚。角色的知识优势存在，但没有替代他人的雇用决定、社会身份和生活成本。
- **归纳机制**：`现代认知/技巧 → 本地可验证服务或角色 → 他人接受/回报 → 组织入口`；每一步都可能失败，不能反写为“知道历史，所以天然能成功”。
- **可回查**：n001/p44、n003/p49、n010/p39、n022/p1；四处原成员与段落 SHA 独立保存在表格 P01 行。
- **竞争解释与适用边界**：陈新的机智、对弱者的援助和强势手段同样在推动早期人脉，不应只归因于专业技术；刘的暂时失业也不能预测他此后一切经营表现。所谓“作者在主张身份理论”并无外部明示，**只能视为结构性解释**。

### P02｜共同改变命运的人，并不共享最终目标或手段的道德边界

- **情节事实**：刘民有能支持一群人的生活，也会拒绝具体骗术分成；陈新倾向通过额外监察控制风险，刘更愿相信具体负责人；两人都参与组织建设，却会因权力运用和情绪底线而分歧。
- **归纳机制**：`外部目标暂时一致 → 人物对权力/风险/人性作出不同估计 → 联合工作仍需分工和妥协 → 分歧在后来的管理现场重新出现`，是持续人物关系，而不是正反派辩论赛。
- **可回查**：n034/p18、n051/p28、n064/p55、n156/p1、n468/p44、n469/p1。n520/p17 是**跨命题补充**：仍只获得有限的试点安排。
- **竞争解释与适用边界**：刘也有操劳、有限见识与不稳定情绪；陈追求权力不等于一切行动只出于私欲。n469/p1 的暂时失落不证明关系彻底断绝。“刘＝作者绝对正确的现代道德化身”没有足够文本依据。

### P03｜名义上的武职、战功和朝廷资源，必须经过层层授权才可能兑现

- **情节事实**：从想得到卫所官职，到发现名额不等于可调兵员，再到京师官场的持续联络成本、官员对奖惩风险的盘算，以及大战前扩军编制争论，作品不断让“纸面上拥有”接受执行检验。
- **归纳机制**：`申请合法入口 → 官吏与中间人转译 → 兵员/基层军官/粮饷匹配 → 实际调动或政治承认`。这不是说官身无用，而是它不是充分条件。
- **可回查**：n052/p28、n081/p1、n221/p21、n303/p22、n494/p17。
- **竞争解释与适用边界**：宋闻贤等人处理官场关系是作品人物可见的具体行动；不能把人物抱怨直接当成历史学上“明朝所有官员都如此”的结论。n155/p52 的战功确实推动了组织地位，这是对“官面全无作用”这一过强结论的反证。

### P04｜经济增长、供应链与民间生产形成不断延长的时间账

- **情节事实**：刘民有同时负担学校、工坊、农工与仓储；海贸合作者若出事，铜料与养兵财源均有风险；跨地商路要支付运费；屯地扩大与既有利益冲突；某些军需品连账簿记录都依赖专业识别。直至决战，仍须花费准备意外延长的运输。
- **归纳机制**：`商业收益 ↔ 劳力/原料/运输 → 可持续行政及军饷 → 扩张产生新需求和新的受损者`。经济不是写一次发明就永久结清的情节。
- **可回查**：n090/p3、n099/p18、n181/p3、n189/p59、n265/p36、n297/p1、n345/p29、n487/p1、n530/p1。
- **竞争解释与适用边界**：这些都是**小说里的场景与人物计划**，不能用作真实财政预算参数。n297/p1 的大订单不等于稳定利润；n345/p29 的同行模仿恰是对“技术垄断可持续”的限制；n530/p1 的风险预留不证明战役确实拖到冬季。

### P05｜组织协同由训练、基层认可和实际反馈构成，而非一项先进武器

- **情节事实**：早期军官通过现场动员建立归属感，武器试制要交由工匠与士卒验证；战争中对手会注意到部队号令和协同；大战前依旧必须组织新营，外部观察者对队伍纪律形成印象。
- **归纳机制**：`愿意接受组织身份 → 明确职责/训练和反馈 → 部属协作 → 对手观察/战争重新检验 → 下一轮组织修正`。
- **可回查**：n070/p36、n105/p13、n400/p43、n488/p1、n514/p34。
- **竞争解释与适用边界**：n514/p34 是蒙古人在有限时间内的外部观察，不能据此宣布所有战兵训练水平一致；n400/p43 是阿巴泰的认识，也不是全知判词；装备、地形、天气、供给仍有作用。叙事归因是**多因并存**。

### P06｜敌我双方都是信息有限、利益不一而能自主行动的群体

- **情节事实**：某卷从皇太极的决策场景开始；另一处陈新得不到确定敌军人数；基层追随者拒绝招抚；皇太极手中关于登州部队人数的回报不一致，朱国斌也只是猜测旗阵背后的政治私心；终局又切到张忠旗不知去向的现场所见。
- **归纳机制**：`多方独立目标 → 各有信息来源与延迟 → 误判/传递 → 行动改变另一方选择 → 读者通过视角交错得到更大的、仍不全知的图景`。
- **可回查**：n106/p1、n140/p36、n375/p30、n390/p16、n501/p24、n556/p3、n567/p1。
- **竞争解释与适用边界**：敌人的某个低阶角色也可能被强制，不可把“有视角”偷换成“有充分自由”；朱国斌推测皇太极私心不是作者明确揭示真实动机；从一个人的不知方向也不能认定所有战场方位都模糊。

### P07｜战争胜利会改变声誉与政治机会，也会制造治理上的新责任

- **情节事实**：文登军的声望扩大，随后地方官署、屯田和社会关系进入新冲突；登州危机并未因既有强军基础自动避免；京师善后仍须打点；调兵命令需要政治协商；胜利消息进入民政办公室，却还不能替代安置和制度工作。
- **归纳机制**：`真实战果 → 奖功/名声/授权 → 军政边界外扩 → 地权、行政、供养与政治反弹 → 下一轮危机`。
- **可回查**：n155/p52、n251/p22、n271/p53、n355/p15、n568/p44。n189/p59 是跨命题“土地反弹”的额外来源。
- **竞争解释与适用边界**：同一组织也确实积累了军事与基础行政能力，所以不应倒过来说扩张只有害处；战后刘民有收到捷报是情节事实，不是治理终局的证明。

### P08｜制度化意味着更可追问的裁量与责任，但本书并不自动宣告其公正

- **情节事实**：陈新处理部属违约时以统帅身份给出理由；后来的基层行政讨论要收回屯长部分物资分配权；军政高层情报与外务职权同桌；陪审试点让普通成员自行论理，两位主角只就有限范围达成安排；协调委员会仍面临资源争议。
- **归纳机制**：`个人命令/既有基层权力 → 暴露分配和监督冲突 → 试行新的参与/分工机制 → 尚待按后续执行结果检验`。这属于**制度争议的故事线**，不是现成的通用治理配方。
- **可回查**：n272/p65、n425/p27、n435/p1、n519/p69、n520/p17、n529/p46。
- **竞争解释与适用边界**：n272/p65 是陈新的辩护，并非作者伦理背书；n425/p27 只是提出收权，不证明已执行；n519/p69 的陪审意见不能推论每次庭审都公平，n520/p17 又明确限制改革范围。后续 R038 要系统审查谁依然无发言权。

### P09｜家庭、普通兵员和依附者的个人选择，不由主帅胜负一次覆盖

- **情节事实**：战果后的分配会产生争议；普通人对婚恋关系有不同期待；战争号令中断朋友对退役和生活的谈话；谢飞的行踪在唐玮当时视野中暂时丢失；关小妹与唐玮关系仍需本人态度；张忠旗面对压迫会调整公开表现。
- **归纳机制**：`公共事件压到个人身上 → 具体人物在资源和身份限制内表达差异 → 其私人结果留在后续章节继续支付`。
- **可回查**：n085/p25、n540/p33、n562/p63、n564/p15、n565/p69、n569/p21。
- **竞争解释与适用边界**：不能说人人拥有平等选择空间；一名服从者的微笑也不能定义其真实心意。**特别反证**：n565/p69 只显示谢飞从唐玮所见的队列里消失，n571/p5 又出现其身影，禁止把前一幕转述为人物死亡；需将限定的观察与终局事实分开。

### P10｜叙述者展示的事实、人物相信的版本和被社会讲述的历史并非同一层

- **情节事实**：早期就出现评书表演；朝廷受理相互冲突的消息；卷末大政治消息打断私人商议；多年后陈新问他人如何评价自己；末章谢飞身份对早前一处现场认知形成限制，说书者又面对更改故事的压力。
- **归纳机制**：`人物现场所见/听闻 → 公文或社会传言 → 声望和利益介入 → 故事后来的修订 → 读者回头重估早前结论`。
- **可回查**：n051/p57、n166/p30、n480/p3、n570/p26、n571/p5、n571/p31、n571/p64。跨命题限定另见 n565/p69。
- **竞争解释与适用边界**：n166 的一次说书仅是提前出现的形式资源，不能伪造作者提前公开宣言；n480 的矛盾塘报不意味着双方必然撒谎；结尾改变的是**历史叙述的评价框架**，不等于整个小说前文全部自动无效。

## 三、命题之间的推导链：谁影响谁，证据不足在哪里

1. **身份链 P01→P03→P05**：知道未来不足以直接指挥；先在当地赢得工作与信用（n001、n010），再取得武职并经军户和基层组织承接（n052、n081），随后才由训练、工匠实践和外部检验形成较可靠的军力（n105、n400）。**反证检查**：n155/p52 确实显示战功可以反向加速官面身份，故因果不是单向的“先完全合法，后才有任何战力”。
2. **资源链 P04→P05→P07**：学校、商路、民生产出与军需支持训练和行动（n090、n099、n181）；成功后的势力增大，又可能与屯地、中央调令及安置发生新的摩擦（n189、n355、n568）。**反证检查**：经济线并非只在军事场景里才出现，它也有刘民有和普通工作人员的自主任务（n090/p3）。
3. **对手链 P06↔P05**：登州军组织水平可在战争场面观察到，但后金决策、下层意志、错误侦察也在独立改变战局（n106、n390、n501）；要检验“训练更强所以每场必胜”，需纳入地形、天气和敌方临场自发行动。**缺口**：本轮不对历史真有哪次战役提供书外权威结论。
4. **权力与伦理链 P02↔P08↔P09**：陈新与刘民有对权力、信任、司法尝试不总一致（n051、n064、n468）；一套强组织会出现收权和陪审议题（n425、n519），还要面对普通人的个人目标和不平等处境（n540、n564）。**反证检查**：对权力不安不自动等于存在可立即替代全部军令的制度方案。
5. **终局与记述链 P07→P09→P10**：军事胜利进入社会新闻与生活安排（n568、n569），老年主角会关心名声评语（n570），茶馆又显示受众与表演者重新塑造讲述（n571）。**逆向检验**：n565/p69→n571/p5 阻止把基层视野直接写成“作者宣布人物死亡”；同一事件的叙述高度与时间位置必须标明。
