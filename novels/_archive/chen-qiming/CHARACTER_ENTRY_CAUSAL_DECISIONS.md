# 《陈启明》｜人物出场与历史分岔决策底稿
状态：作者已确定**判断原则**；本文件的具体人物剧情方案均为`CANDIDATE / UNAPPROVED`，不得作为已发生Canon。

## 不是按戏份多少分配角色，而是按能造成什么后果

|人物层级|认定依据|写作时实际需要知道|是否需远期走向|
|---|---|---|---|
|叙事核心|命运与全书承诺绑在一起；一人选择能改变卷级目标|欲望、性格、现状、可调动资源、独立决定、与其他核心人物的互相影响|必须从出场前推至终局的关键阶段；不等于每章都在场|
|历史杠杆人物|真实权力、部队、官位、商业势力或政治联络，动作会改写区域/朝廷格局|真实年表、职权和制约、已有关系、出场后所有受波及事件|必须提前推演至少覆盖下一个重大历史节点，进一步影响跟进至1644及更远；**只有被提到但已经促使皇帝行动，也算启动了杠杆**|
|长期重要配角|自身目标、生活与关系持续延伸；可以推动多场戏并在后文自主改变局面|人物性格、当前生活、短中期轨迹、哪些选择影响主角|必须有阶段性发展与明确承接；不能只围绕主角办事|
|当章人物|场景内有自己的实际生活与诉求，但不操纵大时代局势|为何此刻出现、做什么、与谁相关、离场之后合理去处|不要求预编千章；**若他做的事形成后续债务/承诺，就必须跟踪**|
|背景人物|无具名决策或只提供可信环境|出场地点、职责与行为合乎现场|没有硬编后续的必要|

判级由**实际影响力**决定，不由作者称呼、善恶、是否在画面内、此章台词数量决定。角色可随剧情升级，升级当章需补齐影响与路线，不能事后倒补。虚构普通人物仍可丰富世界，不必每人变主线；真实历史主要正反角色规则见 `PROJECT_BIBLE.md`。

## 每章实际采用的人物入场办法

动笔前读当前历史状态；仅对本章**实际出现或因提名而触发行动**的人执行：
1. **当日位置**：人在何处、担任何职、认识谁、今天原本在做什么；他不是为主角等候的NPC。
2. **当日选择**：他为什么做/不做这一件事，对谁有利有害，他拥有的权限到底够不够。
3. **人物归属**：核心／历史杠杆／长期配角／当章／背景。不是打标签，紧接着确定他下一次在哪儿发生独立行动。
4. **现实变化**：本章让什么状态真正变了？只是谈到一个名字，还是已经引发皇帝改旨、调人、调钱、放人、保留档案？
5. **历史接续**：若重大人物状态变了，逐条重排受影响的时间、兵力、任免、财政与敌我应对；**不能一边写能力强的角色提前行动，一边让相同历史节点继续原样发生**。
6. **最小交付**：单章只展示有趣的现场；上述推演放在作者内部事件/人物账中，不搬到正文给读者讲课。

一名重要人物如果尚不能说明「为何此时出现」「凭什么起作用」「以后独立做什么」「他改变了哪些既定事件」，便**暂缓让其触发剧情**；既可以延后露面，也可以保留真实背景信息但不让皇帝因此改变处置。不能为章末高潮先出场、后补命运。

## 孙传庭：不可跳过的历史分岔决策

**已核史实基线（小说介入前）：**《明史》卷24记载崇祯十二年五月孙传庭被削籍、继而逮捕入狱；《明史》卷262记其1639入狱、1642年复起，1643年战死。其此前曾独立整顿陕西屯田、兵员、军政，并与杨嗣昌发生实际分歧。该能力意味着「提前复出」不是救出一位普通官员，而是让一名已经证明有组织能力的统帅提前进入政治和军事行动。时间依据：
- https://zh.wikisource.org/zh-hans/明史/卷24
- https://zh.wikisource.org/zh-hans/明史/卷262

**分岔A｜第一章暂不使用其名字（目前的建议默认）**

陈启明当夜优先求生、判断崇祯，对后世重要人名可想到却不必马上说出口。孙传庭仍按1639既有背景处于政治困境；但**陈启明现身、皇帝听闻国运已经是变化源**，不能据此宣布整个1639—1644仍严格照原史运行。好处是长线孙传庭的介入窗口可以在角色设计后选择，不为一个验证身份的桥段预支全部历史分岔。

**分岔B｜1639陈启明说起孙传庭，但皇帝不立即放人**

需要分清「皇帝听见名字」「查卷宗」「保全性命或改变狱中待遇」「实际恢复官职/兵权」，每次真实行动产生不同后果。仅称名不自动使其重获统军权，但皇帝的看法、官员关注和未来任用机会可能已变；记录**信息链**而不是假定什么都没有发生。必须说明陈为什么现在想说，皇帝为什么听得进去。

**分岔C｜1639提前出狱且实际恢复职权、资源（高影响重大改史；未经批准不得采用）**

要重新设计，不许写了出狱便跳回原史：
- **1639—1640**：谁拟旨、哪位官员让位、与杨嗣昌等旧有分歧如何演变；兵员从哪里来、谁发饷、在哪里驻防、朝廷是否真听从建议。
- **1640—1641**：孙传庭有无真实力量改变农民军流动、河南与陕西态势、李自成／张献忠／各部的选择；南阳1641仍面临什么危机，是否规模、时间、参战者都不同。不能写「他能办事，却整整两年什么都没改变」。
- **1642—1643**：真实历史的重新起用与战败节点可能失效，部队损耗、地方官关系、粮运及仓促出兵条件要从新局面推出，不许原样重播。
- **1644**：李自成是否仍有同样军力、京师是否仍受同样威胁、崇祯为何需要获救、如何抵南京，必须重建。**小说已锁定1644救崇祯至南京的作者目标，但这不是史事自动不变的许可**；若分岔使既有威胁消失，就要找出来自先前选择的新、真实可信的危机，不能为兑现目标强行降低孙传庭能力。
- **长期余波**：孙传庭作为有自己权威、所部、家属与政治信念的独立重臣，会改变陈启明的结盟与皇帝对其授军权的考虑，并作用于以后的政权重组。

**分岔D｜1642前后复出，1643命运再改写**

比1639直接复出保留更多史实底盘，但仍是大分岔；若其未在1643败亡，1644战争与政治条件同样需要从新状态推算。不能把「改了他的命」写成他以后长期无所作为。

**结论**：作者尚未决定孙传庭具体命运，B/C/D都是备选，不晋级正史；本案暂按A构思下一版开头，直到能证实有更值得承担长期改变的情节入口。

## 每章留下的真正产物

一份简短`Chapter Character Delta`（人物名／所处位置／本章决定／真实获得与失去／下一站／可能受影响的历史节点），只写发生的，不伪造未写正文；遇高影响历史分岔，另增一张“原历史→新的条件→其他历史人物的下一步反应”事件链。没有角色变化的过场不需要机械出报告；人物因果是作者工作的底稿，不应挤占文学正文。
