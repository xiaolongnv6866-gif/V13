- 新对话、续写、普通原创，都不要把本目录里的 `PROJECT_BIBLE.md`、正文、`STATE.json`、大纲或人物决策当成当前设定。

- 当前活动小说槽是 [`novels/new-work/`](../new-work/)。写作能力仍从 [`skills/v13-writer-mind/SKILL.md`](../../skills/v13-writer-mind/SKILL.md) 进入；技能不随旧设定退役。
